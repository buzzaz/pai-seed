# PAI Seed -- Provenance

Staging repository for the PAI Seed. Structural patterns hardened through operational Personal AI use are generalized here, reviewed, and pushed downstream to the community nursery.

## Provenance Chain

```
Source tree (operational PAI)
    -> m1small/pai-seed (this repo -- staging and review)
        -> Kwaai-AI-Lab/pai-seed (nursery -- community distribution)
```

Updates flow downstream. Community contributions (pattern shares, friction reports) flow upstream through the Kwaai repo's issues and PRs.

## The Kernel

Two files compose the irreducible seed:

- **`CLAUDE.md`** -- Bootstrap. The AI reads this on session start and becomes a PAI seed.
- **`tree.md`** -- Architecture. The tree metaphor, growth cycle, Bonsai Principle, forest awareness.
